# NewsApp 📰

A modern news app built with SwiftUI and MVVM.

## Features

🗞️ Top headlines  
🏷️ Category filtering (Tech, Business, Sports & more)  
🔍 Article details & Web View  
⚡ Async/Await & REST API  
🎨 Clean UI with custom category chips  

## Tech Stack

Swift • SwiftUI • MVVM • URLSession • News API
